# 英语乐园 · 小学 1-6 年级 v2.0

面向小学生的英语学习 PWA，包含单词学习、拼写挑战、翻牌配对、快速抢答、错词间隔复习和成长报告。

## 2.0 功能

- 多个孩子独立学习档案
- 每日目标、连续学习天数和最近 7 天统计
- 全部档案导出、导入和重置
- 拼写练习模式：答错不扣爱心
- 拼写提示：一次提示一个正确字母
- 错词本与 1/2/4/7/15 天间隔复习
- PWA 安装和完全离线使用

## 手机安装

- iPhone：Safari 打开 Pages 地址，点击“分享 → 添加到主屏幕”。
- Android：Chrome 打开 Pages 地址，点击菜单中的“安装应用”。
- 第一次联网打开后，应用会自动缓存并支持离线使用。

学习进度保存在本机浏览器中。

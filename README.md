# 英语乐园 · 小学 1-6 年级

面向小学生的英语学习 PWA，包含音标音节、跟读录音、听音拼写、拼写挑战、错词复习和成长报告。

## 词库

- 当前共 1,332 个词条、912 个去重单词
- 完整覆盖 PEP 小学英语 3-6 年级 732 个去重单词
- 所有单词均配音标和音节数据

## 主要功能

- 发音老师只保留男声、女声两个选项，自动选择最清晰的本地语音
- 听音拼写、拼写练习模式和提示字母
- 跟读录音和本地回放，录音不会上传
- 多个孩子独立档案、每日目标和成长报告
- 数据导出、导入和重置
- 错词本与 1/2/4/7/15 天间隔复习
- PWA 安装和完全离线使用

学习进度保存在本机浏览器中。
